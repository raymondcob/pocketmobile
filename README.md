# Pocket Mobile Website

A responsive e-commerce website for Pocket Mobile, a mobile technology company offering devices, accessories and repair services.

## Description

The Pocket Mobile website is built using HTML, CSS and Bootstrap 5. It showcases various products and services including:

- Mobile phones and tablets
- Phone cases and accessories  
- Chargers and power banks
- Screen protectors and tempered glass
- Repair services

## Features

- Responsive design that works on desktop and mobile
- Product catalog with categories:
  - Electronics (phones, tablets, watches)
  - Cases (phone cases, tablet cases)
  - Chargers (wall chargers, power banks)
  - Tempered Glass
  - Other Accessories
- Services section highlighting repair offerings
- Location information with map link
- Social media integration
- Contact information

## Tech Stack

- HTML5
- CSS3 
- Bootstrap 5.3.3
- Font Awesome icons
- Bootstrap Icons
- AOS (Animate On Scroll) library

## Pages

- `index.html` - Home page with company info and services
- `pages/Electronics.html` - Mobile devices and electronics
- `pages/Cases.html` - Phone and tablet cases
- `pages/Chargers.html` - Charging accessories
- `pages/Glass.html` - Screen protectors
- `pages/Other.html` - Additional accessories

## Setup

1. Clone the repository
2. Open in a web server (e.g. XAMPP)
3. Navigate to the site through your web browser
